\section{The starting point: a recurrent neural network}

The paper studies firing-rate recurrent neural networks. A common continuous-time
form is
\begin{equation}
  \tau \frac{d x_i}{dt}
  =
  -x_i
  +
  \sum_{j=1}^{N} J_{ij}\,\phi(x_j)
  +
  \sum_{s=1}^{N_{\mathrm{in}}} I_i^{(s)} u_s(t),
  \label{eq:rnn_component}
\end{equation}
where:
\begin{itemize}
  \item $x_i(t)$ is the activation of neuron $i$;
  \item $\phi(x_i)$ is its firing rate after a static nonlinearity;
  \item $J_{ij}$ is the recurrent weight from neuron $j$ to neuron $i$;
  \item $u_s(t)$ are external inputs, such as stimulus or context signals;
  \item $I_i^{(s)}$ is the input weight from input channel $s$ to neuron $i$.
\end{itemize}

In vector form,
\begin{equation}
  \tau \dot{\vx}
  =
  -\vx + J\phi(\vx) + \sum_s \vI^{(s)}u_s(t).
\end{equation}
A completely general $N \times N$ recurrent matrix $J$ can have rank as large as
$N$. Such a matrix can create many independent recurrent feedback directions.
The low-rank assumption sharply restricts this.

\section{What ``low rank'' means}

A rank-$R$ recurrent connectivity matrix can be written as a sum of $R$ outer
products:
\begin{equation}
  J
  =
  \frac{1}{N}
  \sum_{r=1}^{R} \vm^{(r)} \left(\vn^{(r)}\right)^{\top},
  \label{eq:lowrank_matrix}
\end{equation}
or componentwise,
\begin{equation}
  J_{ij}
  =
  \frac{1}{N}
  \sum_{r=1}^{R} m_i^{(r)} n_j^{(r)}.
\end{equation}

Each term has two population-length vectors:
\begin{itemize}
  \item $\vn^{(r)}$ is a \emph{read-in} or \emph{selection} vector. It defines
  which population activity pattern is measured.
  \item $\vm^{(r)}$ is a \emph{write-out} vector. It defines which pattern of
  recurrent input is sent back into the neurons.
\end{itemize}

For rank one,
\begin{equation}
  J = \frac{1}{N}\vm\vn^\top,
\end{equation}
so recurrent processing has a simple form:
\begin{equation}
  J\phi(\vx)
  =
  \vm
  \left(
    \frac{1}{N}\vn^\top \phi(\vx)
  \right).
\end{equation}
The network first projects the current firing rates onto $\vn$, producing one
scalar, and then feeds that scalar back along $\vm$.

\section{The latent variable}

The scalar produced by the projection is the key low-dimensional variable:
\begin{equation}
  \kappa(t)
  =
  \frac{1}{N}
  \sum_{j=1}^{N} n_j \phi(x_j(t)).
  \label{eq:kappa_rank_one}
\end{equation}
For rank one, the recurrent input to neuron $i$ is simply
\begin{equation}
  m_i \kappa(t).
\end{equation}
Thus the full $N$-dimensional network is not using an arbitrary recurrent input
pattern. Its recurrent input always lies along the single population direction
$\vm$. For rank $R$, there are $R$ such latent variables:
\begin{equation}
  \kappa_r(t)
  =
  \frac{1}{N}
  \sum_{j=1}^{N} n_j^{(r)} \phi(x_j(t)),
  \qquad r=1,\ldots,R.
\end{equation}
The recurrent input is then
\begin{equation}
  J\phi(\vx)
  =
  \sum_{r=1}^{R} \vm^{(r)}\kappa_r(t).
  \label{eq:recurrent_low_dim}
\end{equation}

This is the main mathematical reason low-rank networks are interpretable: the
large neural population can be described through a small set of recurrent latent
variables $\kappa_1,\ldots,\kappa_R$.

\section{Why low-rank connectivity creates low-dimensional dynamics}

Insert the low-rank form into the RNN:
\begin{equation}
  \tau \dot{\vx}
  =
  -\vx
  +
  \sum_{r=1}^{R} \vm^{(r)}\kappa_r(t)
  +
  \sum_s \vI^{(s)}u_s(t).
  \label{eq:low_dim_state}
\end{equation}
This equation says that changes in the neural state are built only from:
\begin{itemize}
  \item the recurrent directions $\vm^{(1)},\ldots,\vm^{(R)}$;
  \item the input directions $\vI^{(1)},\ldots,\vI^{(N_{\mathrm{in}})}$;
  \item the leak term $-\vx$.
\end{itemize}

If the initial state is in the subspace spanned by the recurrent and input
directions, it stays there. Even when the full network has thousands of neurons,
the meaningful trajectories can live in a much smaller subspace. This is what the
paper means by reducing the network to latent dynamics.

\section{A rank-one example}

With one input $u(t)$ and rank-one recurrent connectivity,
\begin{equation}
  \tau \dot{x}_i
  =
  -x_i + m_i \kappa(t) + I_i u(t),
\end{equation}
\begin{equation}
  \kappa(t)
  =
  \frac{1}{N}
  \sum_j n_j \phi(x_j(t)).
\end{equation}

If $\phi$ were linear, the latent dynamics would be approximately
\begin{equation}
  \tau \dot{\kappa}
  =
  -\kappa
  +
  \sigma_{nm}\kappa
  +
  \sigma_{nI}u(t),
  \label{eq:linear_kappa}
\end{equation}
where
\begin{equation}
  \sigma_{nm} = \frac{1}{N}\sum_i n_i m_i,
  \qquad
  \sigma_{nI} = \frac{1}{N}\sum_i n_i I_i.
\end{equation}

These overlaps control the computation:
\begin{itemize}
  \item $\sigma_{nI}$ says how strongly the input drives the latent variable;
  \item $\sigma_{nm}$ says how strongly the latent variable feeds back onto itself.
\end{itemize}
If feedback is weak, $\kappa$ tracks the input briefly. If feedback is tuned close
to the leak, $\kappa$ can integrate information over time. If the nonlinearity is
strong and feedback is positive, the same low-dimensional system can support
attractor-like decision states.

\section{Where population structure enters}

The paper then asks: what statistics of the neuron-specific parameters are needed
for a task? For each neuron, collect its coordinates in connectivity space:
\begin{equation}
  \left(
    m_i^{(1)},\ldots,m_i^{(R)},
    n_i^{(1)},\ldots,n_i^{(R)},
    I_i^{(1)},\ldots,I_i^{(N_{\mathrm{in}})},
    w_i
  \right).
\end{equation}
Across neurons, these coordinates form a distribution.

\subsection*{Single random population}

In a fully random population structure, these neuron coordinates are modeled as
draws from one joint distribution, often a multivariate Gaussian:
\begin{equation}
  \mathbf{a}_i \sim \mathcal{N}(0,\Sigma).
\end{equation}
The effective latent dynamics are governed by global covariances such as
$\sigma_{nm}$ and $\sigma_{nI}$. There are no distinct groups of neurons with
different computational roles.

\subsection*{Multiple subpopulations}

In a non-random population structure, the coordinates are better described as a
mixture:
\begin{equation}
  p(\mathbf{a})
  =
  \sum_{p=1}^{P}
  \alpha_p \mathcal{N}(\mu_p,\Sigma_p).
\end{equation}
Each component corresponds to a subpopulation. The subpopulations can have
different covariances, so the same input may modulate one group strongly and
another weakly.

In the nonlinear case, this is crucial. Dubreuil et al. write the effective couplings
as population-weighted quantities of the form
\begin{equation}
  \widetilde{\sigma}_{ab}
  =
  \sum_p
  \alpha_p
  \sigma_{ab}^{(p)}
  \langle \phi' \rangle_p.
\end{equation}
Here $\langle \phi' \rangle_p$ is the gain of subpopulation $p$. Inputs can change
these gains differently across subpopulations. This lets context reshape the
effective latent dynamics without necessarily driving the same latent variable
directly.

\section{The computational message}

Low rank controls the \emph{dimension} of the recurrent dynamics. A rank-$R$
network has $R$ main recurrent latent variables.

Population structure controls how inputs, feedback, and readout are arranged
across neurons. A single random population can implement many tasks by using
low-dimensional dynamics. But tasks requiring flexible input-output remapping can
require multiple subpopulations, because different groups need to have different
gain modulations and different effective roles.

In one sentence:

\begin{quote}
Low-rank connectivity says the network computes through a small number of
collective variables; non-random population structure says different neurons are
organized so that inputs can flexibly reshape the dynamics of those collective
variables.
\end{quote}

\section{The concrete model in the task}

The task asks for a recurrent neural network with one-dimensional input
$u(t) \in \R$, one-dimensional output $z(t) \in \R$, and $N$ recurrent units.
The continuous-time state of neuron $i$ is $x_i(t)$. Its firing rate is
\begin{equation}
  r_i(t) = \phi(x_i(t)) = \tanh(x_i(t)).
\end{equation}
The dynamics are
\begin{equation}
  \tau \frac{d x_i}{dt}
  =
  -x_i
  +
  \sum_{j=1}^{N} J_{ij}\phi(x_j)
  +
  I_i u(t),
  \qquad i=1,\ldots,N,
  \label{eq:task_continuous}
\end{equation}
with neuronal time constant $\tau = 100\text{ ms}$.

The recurrent matrix is rank one:
\begin{equation}
  J = \frac{1}{N}\vm\vn^\top,
  \qquad
  J_{ij} = \frac{1}{N}m_i n_j.
  \label{eq:rank_one_J}
\end{equation}
The output is a linear readout of the rates:
\begin{equation}
  z(t)
  =
  \frac{1}{N}\sum_{i=1}^{N}w_i\phi(x_i(t)).
  \label{eq:task_output}
\end{equation}

Only $\vm$ and $\vn$ are trainable. The input vector $\vI$ and output vector
$\vw$ are fixed after initialization. All trainable and fixed parameters are
sampled from standard normal distributions, except $\vw$, which is sampled with
standard deviation $4$.

\subsection{Vector form}

Let $\vx(t) \in \R^N$, $\vI,\vm,\vn,\vw \in \R^N$, and
$\phi(\vx)$ mean applying $\tanh$ elementwise. Then
\begin{equation}
  \tau \dot{\vx}
  =
  -\vx
  +
  \frac{1}{N}\vm\vn^\top\phi(\vx)
  +
  \vI u(t).
  \label{eq:vector_continuous}
\end{equation}
Because $J$ is rank one, it is better not to explicitly build the full
$N \times N$ matrix. Define the scalar recurrent coordinate
\begin{equation}
  \kappa(t)
  =
  \frac{1}{N}\vn^\top \phi(\vx(t)).
  \label{eq:kappa}
\end{equation}
Then the recurrent input is simply
\begin{equation}
  J\phi(\vx(t)) = \vm \kappa(t).
\end{equation}
So the implemented update can use one dot product with $\vn$, then multiply by
$\vm$. This is both clearer and cheaper than forming $J$.

\section{What an RNN is doing}

A recurrent neural network is a dynamical system with memory. A feedforward
network computes
\begin{equation}
  y = f_\theta(u)
\end{equation}
from the current input alone. An RNN computes from both the current input and an
internal state:
\begin{equation}
  \vx_{t+1} = F_\theta(\vx_t, u_t),
  \qquad
  z_t = G_\theta(\vx_t).
\end{equation}
The state $\vx_t$ carries information from earlier inputs. In this task, the
state is a population of firing-rate units. The leak term $-\vx$ makes old
activity decay, the recurrent term feeds current activity back into the network,
and the input term injects the stimulus.

The nonlinearity matters. Here $\phi = \tanh$ maps activations to rates in
$(-1,1)$. Around zero, $\tanh(x) \approx x$, so the network behaves almost
linearly. For large positive or negative activations, $\tanh$ saturates and
$\phi'(x) = 1 - \tanh^2(x)$ becomes small. Saturation can stabilize activity, but
it can also make gradients small during training.

\section{From the differential equation to code}

The task specifies forward Euler simulation with
\[
  \dt = 20\text{ ms}.
\]
Since $\tau = 100\text{ ms}$,
\[
  \alpha = \frac{\dt}{\tau} = \frac{20}{100} = 0.2.
\]
Forward Euler replaces $\dot{\vx}(t)$ by
\[
  \frac{\vx_{t+1} - \vx_t}{\dt}.
\]
Substituting into Equation~\ref{eq:vector_continuous} gives
\begin{equation}
  \vx_{t+1}
  =
  \vx_t
  +
  \alpha
  \left[
    -\vx_t
    +
    \vm\kappa_t
    +
    \vI u_t
  \right],
  \label{eq:euler_update}
\end{equation}
where
\begin{equation}
  \kappa_t = \frac{1}{N}\vn^\top\tanh(\vx_t).
\end{equation}
Equivalently,
\begin{equation}
  \vx_{t+1}
  =
  (1-\alpha)\vx_t
  +
  \alpha\vm\kappa_t
  +
  \alpha\vI u_t.
  \label{eq:euler_expanded}
\end{equation}
This is the exact recurrence to implement.

If the stimulus lasts $75$ time steps, the real duration is
\[
  75 \times 20\text{ ms} = 1500\text{ ms}.
\]

\section{Tensor shapes for a batch implementation}

Use a batch dimension so many trials can be simulated at once. One convenient
layout is:
\begin{center}
\begin{tabular}{@{}lll@{}}
\toprule
Quantity & Shape & Meaning \\
\midrule
\texttt{u} & \texttt{(batch, time)} & scalar input sequence for each trial \\
\texttt{x} & \texttt{(batch, N)} & current recurrent state \\
\texttt{rates} & \texttt{(batch, N)} & \texttt{tanh(x)} \\
\texttt{m, n, I, w} & \texttt{(N,)} & population vectors \\
\texttt{kappa} & \texttt{(batch,)} & recurrent latent coordinate \\
\texttt{z} & \texttt{(batch,)} & scalar output at one time step \\
\texttt{outputs} & \texttt{(batch, time)} & full output sequence \\
\bottomrule
\end{tabular}
\end{center}

With this layout, the low-rank computations are:
\begin{align}
  \kappa_t^{(b)}
  &=
  \frac{1}{N}\sum_{i=1}^{N} n_i \tanh(x_{t,i}^{(b)}),
  \\
  z_t^{(b)}
  &=
  \frac{1}{N}\sum_{i=1}^{N} w_i \tanh(x_{t,i}^{(b)}),
\end{align}
where $b$ indexes the trial in the batch.

In PyTorch, these become:
\begin{lstlisting}[style=python]
rates = torch.tanh(x)              # (batch, N)
kappa = (rates * n).mean(dim=1)    # (batch,)
z = (rates * w).mean(dim=1)        # (batch,)
\end{lstlisting}
The use of \texttt{mean(dim=1)} implements the factor $1/N$.

\section{Initialization and the role of the output scale}

The vectors should be initialized as
\begin{align}
  m_i &\sim \mathcal{N}(0,1), &
  n_i &\sim \mathcal{N}(0,1), &
  I_i &\sim \mathcal{N}(0,1), &
  w_i &\sim \mathcal{N}(0,4^2).
\end{align}
The larger standard deviation for $\vw$ compensates for the averaging in the
readout. At random initialization, if the rates are only weakly aligned with
$\vw$, the sum
\[
  \frac{1}{N}\sum_i w_i r_i
\]
has a typical scale proportional to $\operatorname{std}(w)/\sqrt{N}$ rather than
$\operatorname{std}(w)$. A larger output scale helps keep the initial output from
being extremely small for moderate $N$. It does not make $\vw$ trainable; it only
sets the fixed readout scale.

\section{Trainable parameters versus fixed buffers}

In PyTorch, trainable parameters should be \texttt{nn.Parameter} objects. Fixed
tensors that belong to the model should be registered as buffers. Buffers move
with the model when calling \texttt{model.to(device)}, are saved in the
\texttt{state\_dict}, but are not updated by the optimizer.

For this task:
\begin{center}
\begin{tabular}{@{}lll@{}}
\toprule
Vector & PyTorch representation & Optimizer updates it? \\
\midrule
$\vm$ & \texttt{nn.Parameter} & yes \\
$\vn$ & \texttt{nn.Parameter} & yes \\
$\vI$ & \texttt{register\_buffer("I", ...)} & no \\
$\vw$ & \texttt{register\_buffer("w", ...)} & no \\
\bottomrule
\end{tabular}
\end{center}

\section{A minimal PyTorch module}

This is the core implementation pattern. It avoids forming $J$ and unrolls the
dynamics over time.

\begin{lstlisting}[style=python]
import torch
from torch import nn


class RankOneRNN(nn.Module):
    def __init__(self, n_units: int, dt_ms: float = 20.0, tau_ms: float = 100.0):
        super().__init__()
        self.n_units = n_units
        self.alpha = dt_ms / tau_ms

        self.m = nn.Parameter(torch.randn(n_units))
        self.n = nn.Parameter(torch.randn(n_units))

        self.register_buffer("I", torch.randn(n_units))
        self.register_buffer("w", 4.0 * torch.randn(n_units))

    def forward(self, u: torch.Tensor, x0: torch.Tensor | None = None):
        # u has shape (batch, time)
        batch_size, n_steps = u.shape

        if x0 is None:
            x = u.new_zeros(batch_size, self.n_units)
        else:
            x = x0

        outputs = []
        states = []

        for t in range(n_steps):
            rates = torch.tanh(x)

            z = (rates * self.w).mean(dim=1)
            outputs.append(z)
            states.append(x)

            kappa = (rates * self.n).mean(dim=1)
            recurrent = kappa[:, None] * self.m[None, :]
            external = u[:, t, None] * self.I[None, :]

            x = x + self.alpha * (-x + recurrent + external)

        outputs = torch.stack(outputs, dim=1)
        states = torch.stack(states, dim=1)
        return outputs, states
\end{lstlisting}

Important shape details:
\begin{itemize}
  \item \texttt{kappa} has shape \texttt{(batch,)}.
  \item \texttt{kappa[:, None]} has shape \texttt{(batch, 1)}.
  \item \texttt{self.m[None, :]} has shape \texttt{(1, N)}.
  \item Their product broadcasts to \texttt{(batch, N)}.
\end{itemize}

\section{Training objective}

Training means choosing $\vm$ and $\vn$ so the output sequence $z_t$ matches a
target sequence $y_t$. For the assignment, use a network of size
\[
  N = 128.
\]
The target is only defined during the final decision epoch. If the simulated
sequence has length $T_{\mathrm{sim}}$, define the decision window as the last
\[
  T_{\mathrm{dec}} = 15
\]
time steps. The loss should not penalize the network during earlier stimulus or
delay time steps. It only asks whether the final decision-period output is close
to the target.

For a mini-batch of $B$ trials, the assignment's loss is
\begin{equation}
  \mathcal{L}(\vm,\vn)
  =
  \frac{1}{B T_{\mathrm{dec}}}
  \sum_{b=1}^{B}
  \sum_{s=1}^{T_{\mathrm{dec}}}
  \left(
    z_{t_s}^{(b)} - y_{t_s}^{(b)}
  \right)^2,
  \label{eq:decision_loss}
\end{equation}
where $t_s = T_{\mathrm{sim}} - T_{\mathrm{dec}} + s$ indexes the final
15 time steps. The problem statement writes the trial index as $i$; here $b$ is
used instead to avoid confusing trials with neurons.

The instruction says to use stochastic gradient descent, specifically Adam, with
\[
  B = 32,
  \qquad
  \eta = 5 \times 10^{-3}.
\]
In practice, this means each parameter update uses one mini-batch of 32 trials,
computes the average decision-window MSE, backpropagates that scalar loss, and
lets Adam update only $\vm$ and $\vn$. A successful implementation should reach a
loss below roughly $5 \times 10^{-2}$, possibly after about 1000 parameter
updates.

In code:
\begin{lstlisting}[style=python]
decision_steps = 15

outputs, states = model(u_batch)           # outputs: (batch, time)
output_decision = outputs[:, -decision_steps:]

# If target is already a time series, keep only its decision window.
# If target is one scalar per trial, repeat it across the decision window.
if target_batch.ndim == 2:
    target_decision = target_batch[:, -decision_steps:]
else:
    target_decision = target_batch[:, None].expand_as(output_decision)

loss = ((output_decision - target_decision) ** 2).mean()
\end{lstlisting}

\section{Task-specific training loop}

A full training step has four conceptual stages:
\begin{enumerate}
  \item Generate or sample a mini-batch of input trials and targets.
  \item Run the RNN forward through the full input sequence, storing outputs and
  hidden states.
  \item Compute MSE only on the last 15 decision time steps.
  \item Backpropagate through the unrolled recurrence and update $\vm,\vn$ with
  Adam.
\end{enumerate}

\begin{lstlisting}[style=python]
model = RankOneRNN(n_units=128)
optimizer = torch.optim.Adam(model.parameters(), lr=5e-3)

batch_size = 32
decision_steps = 15

for update in range(1000):
    u_batch, target_batch = make_batch(batch_size)

    optimizer.zero_grad(set_to_none=True)
    outputs, states = model(u_batch)

    output_decision = outputs[:, -decision_steps:]
    if target_batch.ndim == 2:
        target_decision = target_batch[:, -decision_steps:]
    else:
        target_decision = target_batch[:, None].expand_as(output_decision)

    loss = ((output_decision - target_decision) ** 2).mean()
    loss.backward()
    optimizer.step()

    if update % 100 == 0:
        print(update, float(loss))
\end{lstlisting}

This code assumes \texttt{make\_batch(32)} returns an input tensor with shape
\texttt{(32, time)}. The target can either be a full target time series with
shape \texttt{(32, time)} or one desired decision value per trial with shape
\texttt{(32,)}.

\section{How training works: backpropagation through time}

The forward pass unrolls the recurrence:
\begin{align}
  \vx_1 &= F_\theta(\vx_0, u_0),\\
  \vx_2 &= F_\theta(\vx_1, u_1),\\
  &\vdots\\
  \vx_T &= F_\theta(\vx_{T-1}, u_{T-1}),
\end{align}
where $\theta = \{\vm,\vn\}$ in this task.

The loss depends on all states through the outputs:
\[
  \mathcal{L}
  =
  \sum_{t \in \text{decision window}} \ell(G(\vx_t), y_t).
\]
This is important: the error is measured only at the end, but the hidden state at
the end depends on every earlier input and every earlier recurrent update.
Backpropagation through time is ordinary backpropagation applied to the unrolled
computation graph. The same parameters $\vm$ and $\vn$ are reused at every time
step, so their gradients accumulate contributions from every step:
\[
  \frac{\partial \mathcal{L}}{\partial \theta}
  =
  \sum_{t \in \text{decision window}}
  \frac{\partial \mathcal{L}}{\partial \vx_t}
  \frac{\partial \vx_t}{\partial \theta}.
\]
The term $\partial \vx_t / \partial \theta$ already contains the whole history
from the initial state up to time $t$. The dependence of later states on earlier
states introduces products of Jacobians:
\[
  \frac{\partial \vx_t}{\partial \vx_s}
  =
  \prod_{q=s}^{t-1}
  \frac{\partial F_\theta(\vx_q,u_q)}{\partial \vx_q},
  \qquad s < t.
\]
If these products shrink, gradients vanish. If they grow, gradients explode.
The leak, the factor $\alpha=0.2$, the low rank, and the saturation of $\tanh$
all affect this gradient flow.

PyTorch builds the graph automatically while the loop runs. Calling
\texttt{loss.backward()} computes the gradients; calling
\texttt{optimizer.step()} updates only \texttt{nn.Parameter} tensors.
Do not detach \texttt{x} or \texttt{states} inside the forward loop during normal
training; detaching would cut the gradient path from the decision loss back to
earlier stimulus processing. Gradient clipping is not part of the mathematical
model, but it can be useful if training produces very large gradients.

\section{Debugging failed convergence}

If the loss does not get below roughly $5 \times 10^{-2}$, first debug the
training setup before interpreting the result as a scientific failure.
\begin{enumerate}
  \item \textbf{Overfit one fixed mini-batch.} Generate one batch of 32 trials,
  reuse exactly that batch for every update, and check whether the loss can be
  driven very low. If this fails, suspect a bug in the recurrence, target
  alignment, loss window, or optimizer setup.
  \item \textbf{Train a full-rank network.} Temporarily replace the rank-one
  recurrent term by a trainable full matrix. If the full-rank model learns but
  the rank-one model does not, the data and loss pipeline are probably working.
  If the full-rank model also fails, the issue is likely in the implementation
  rather than in the rank constraint.
  \item \textbf{Inspect dynamics after convergence.} Plot representative inputs,
  outputs, targets, and hidden-state summaries. Useful hidden summaries include
  $\kappa_t$, the readout $z_t$, and a few hidden units or low-dimensional
  projections of \texttt{states}.
\end{enumerate}

The most common target-alignment bug is accidentally computing loss over the
whole sequence. That trains the network to match undefined or irrelevant targets
during stimulus presentation. For this assignment, slice the last 15 time steps:
\begin{lstlisting}[style=python]
output_decision = outputs[:, -15:]
target_decision = target[:, -15:]  # or label[:, None].expand_as(output_decision)
loss = ((output_decision - target_decision) ** 2).mean()
\end{lstlisting}

\section{What gradients hit in this rank-one model}

The trainable vectors influence the network differently.

The vector $\vn$ determines what population activity is measured:
\[
  \kappa_t = \frac{1}{N}\sum_i n_i r_{t,i}.
\]
Changing $\vn$ changes the scalar feedback signal extracted from the rates.

The vector $\vm$ determines where that scalar is written back:
\[
  \text{recurrent input}_{t,i} = m_i\kappa_t.
\]
Changing $\vm$ changes which neurons receive positive or negative recurrent
drive.

Because $\vw$ is fixed, training cannot directly rotate the output readout.
Instead, it must shape the recurrent dynamics so that the fixed readout
\[
  z_t = \frac{1}{N}\vw^\top \tanh(\vx_t)
\]
becomes task-correct.

\section{Low-rank interpretation}

A full recurrent matrix has $N^2$ entries and can mix neural activity in many
directions. The rank-one matrix
\[
  J = \frac{1}{N}\vm\vn^\top
\]
has only two length-$N$ vectors. It performs two operations:
\begin{enumerate}
  \item read the current rates along $\vn$ to get one scalar $\kappa$;
  \item write that scalar back into the population along $\vm$.
\end{enumerate}
This makes the recurrent part of the dynamics low-dimensional:
\[
  \tau\dot{\vx} = -\vx + \vm\kappa(t) + \vI u(t).
\]
Even though the state $\vx$ has $N$ components, the recurrent feedback has only
one degree of freedom. The main computation can often be understood by tracking
$\kappa(t)$ and the output $z(t)$.

For intuition, suppose $\tanh(x) \approx x$. Then
\[
  \tau \dot{\kappa}
  \approx
  -\kappa
  +
  \sigma_{nm}\kappa
  +
  \sigma_{nI}u(t),
\]
where
\[
  \sigma_{nm} = \frac{1}{N}\sum_i n_i m_i,
  \qquad
  \sigma_{nI} = \frac{1}{N}\sum_i n_i I_i.
\]
The overlap $\sigma_{nI}$ controls how strongly the input drives the latent
coordinate. The overlap $\sigma_{nm}$ controls recurrent feedback. Training
$\vm$ and $\vn$ changes these overlaps and thereby changes whether activity
decays quickly, integrates evidence, or moves toward stable decision-like states.

\section{Practical implementation checks}

Before training on the full task, test the model in small pieces:
\begin{enumerate}
  \item Check that \texttt{model(u)} returns \texttt{outputs} with shape
  \texttt{(batch, time)} and \texttt{states} with shape
  \texttt{(batch, time, N)}.
  \item Check that only \texttt{m} and \texttt{n} appear in
  \texttt{list(model.parameters())}.
  \item Check that \texttt{I} and \texttt{w} appear in
  \texttt{model.state\_dict()} but not in the optimizer parameters.
  \item Feed zero input and verify that the zero initial state stays zero.
  \item Feed a simple constant input and verify that states and outputs are
  finite, not \texttt{nan} or \texttt{inf}.
  \item Run one training step and verify that \texttt{m.grad} and
  \texttt{n.grad} are not \texttt{None}.
\end{enumerate}

Example checks:
\begin{lstlisting}[style=python]
u = torch.randn(8, 75)
model = RankOneRNN(n_units=128)
outputs, states = model(u)

assert outputs.shape == (8, 75)
assert states.shape == (8, 75, 128)
assert torch.isfinite(outputs).all()

loss = outputs.pow(2).mean()
loss.backward()
assert model.m.grad is not None
assert model.n.grad is not None
assert model.I.grad is None
assert model.w.grad is None
\end{lstlisting}

\section{Common pitfalls}

\begin{itemize}
  \item Forgetting the factor $1/N$. In code, use \texttt{mean(dim=1)} or divide
  sums by \texttt{n\_units}.
  \item Accidentally making $\vI$ or $\vw$ trainable. They should be buffers for
  this task.
  \item Building the full $J$ matrix unnecessarily. For rank one, use
  \texttt{kappa * m}.
  \item Mixing time and batch dimensions. Pick one layout and keep it consistent.
  \item Detaching the state inside the time loop during normal full-sequence
  training. Detaching cuts the gradient path through time.
  \item Using in-place tensor operations on values needed for autograd. Prefer
  assignments like \texttt{x = x + ...}.
  \item Computing the output only after the update when the target expects output
  before the update, or vice versa. Choose the convention deliberately and keep
  targets aligned with it.
\end{itemize}

\section{Minimal mental model}

At each time step, the network does the following:
\begin{enumerate}
  \item Convert activations to firing rates:
  \[
    \vr_t = \tanh(\vx_t).
  \]
  \item Read the population along $\vn$:
  \[
    \kappa_t = \frac{1}{N}\vn^\top\vr_t.
  \]
  \item Produce the output through the fixed readout:
  \[
    z_t = \frac{1}{N}\vw^\top\vr_t.
  \]
  \item Combine leak, recurrent feedback, and input:
  \[
    \vx_{t+1}
    =
    \vx_t
    +
    0.2
    \left[
      -\vx_t + \vm\kappa_t + \vI u_t
    \right].
  \]
  \item During training, compare $z_t$ to the target, backpropagate through the
  unrolled steps, and update only $\vm$ and $\vn$.
\end{enumerate}

That is the core of the assignment: implement this recurrence correctly,
generate outputs over time, define a task loss, and let PyTorch's autograd tune
the two low-rank connectivity vectors.

\section{Connectivity space: what it is and how the paper analyzes it}

The paper uses two complementary views of the same low-rank network.

The first view is \emph{activity state space}. This is the familiar
$N$-dimensional space whose coordinates are the neural activities
$x_1,\ldots,x_N$. A trajectory in this space is the population activity evolving
over time.

The second view is \emph{connectivity space}, also called \emph{loading space}
in the paper. This is not the space of activities. It is the space of
neuron-specific parameters. Each neuron is represented by one point whose
coordinates are that neuron's entries in the input, recurrent, and readout
patterns.

For a network with $N_{\mathrm{in}}$ input patterns, one readout pattern, and
rank $R$ recurrent connectivity, neuron $i$ has coordinates
\begin{equation}
  \mathbf{a}_i
  =
  \left(
    I_i^{(1)},\ldots,I_i^{(N_{\mathrm{in}})},
    n_i^{(1)},m_i^{(1)},\ldots,n_i^{(R)},m_i^{(R)},
    w_i
  \right).
  \label{eq:loading_vector_general}
\end{equation}
So the loading-space dimension is
\[
  N_{\mathrm{in}} + 2R + 1
\]
when there is one readout. In the assignment's rank-one, one-input model, each
neuron is just a point in a four-dimensional space:
\begin{equation}
  \mathbf{a}_i = (I_i,n_i,m_i,w_i).
  \label{eq:loading_vector_rank_one}
\end{equation}

This representation is useful because a trained low-rank RNN is not only a list
of vectors $\vI,\vn,\vm,\vw$. It is also a cloud of $N$ points
$\mathbf{a}_1,\ldots,\mathbf{a}_N$ in loading space. The shape of that cloud
describes how input drive, recurrent selection, recurrent feedback, and output
readout are statistically arranged across neurons.

\subsection{The same vectors have two different interpretations}

The columns and rows of the connectivity-pattern matrix answer different
questions.

As \emph{columns}, the patterns $\vI$, $\vm$, $\vn$, and $\vw$ are directions
across the neural population. For example, $\vm$ is a direction in activity
state space: when the latent variable $\kappa$ is positive, recurrent feedback
pushes the state along $\vm$.

As \emph{rows}, the same numbers define one coordinate vector per neuron. For
rank one,
\[
  \begin{array}{c}
  \text{neuron }1\\
  \text{neuron }2\\
  \vdots\\
  \text{neuron }N
  \end{array}
  \left[
  \begin{array}{cccc}
  I_1 & n_1 & m_1 & w_1\\
  I_2 & n_2 & m_2 & w_2\\
  \vdots & \vdots & \vdots & \vdots\\
  I_N & n_N & m_N & w_N
  \end{array}
  \right].
\]
Each row is one point in connectivity space. Each column is one population
pattern.

This is the central duality in the figures from the paper:
\begin{itemize}
  \item activity state space explains \emph{where the neural trajectory can go};
  \item connectivity space explains \emph{why the reduced trajectory has the
  particular inputs, feedback loops, and readout it has}.
\end{itemize}

\subsection{From a point cloud to covariances}

The paper's main simplification is that, for large networks, the exact identity
of every neuron is less important than the distribution of points in loading
space. A common assumption is that the points are sampled from a Gaussian
distribution:
\begin{equation}
  \mathbf{a}_i \sim \mathcal{N}(0,\Sigma).
  \label{eq:single_loading_gaussian}
\end{equation}
The covariance matrix $\Sigma$ summarizes the shape and orientation of the point
cloud. Its entries are pattern overlaps:
\begin{equation}
  \sigma_{ab}
  =
  \frac{1}{N}\sum_{i=1}^{N} a_i b_i,
  \label{eq:pattern_covariance}
\end{equation}
where $a$ and $b$ can be $I$, $n$, $m$, $w$, or one of their indexed versions.
For example,
\[
  \sigma_{nI} = \frac{1}{N}\sum_i n_i I_i,
  \qquad
  \sigma_{nm} = \frac{1}{N}\sum_i n_i m_i,
  \qquad
  \sigma_{mw} = \frac{1}{N}\sum_i m_i w_i.
\]

These covariances are exactly the quantities that appeared earlier in the
rank-one latent dynamics. The connectivity-space view explains why: a covariance
is a geometric feature of the loading cloud, and the reduced dynamics are
controlled by those geometric features.

Pairwise scatterplots are two-dimensional projections of this loading-space
cloud. If the scatterplot of $n_i$ against $I_i$ has a strong positive tilt, then
neurons with positive input weights also tend to have positive $n$ loadings. The
input is therefore read efficiently into $\kappa$. If the scatterplot of $n_i$
against $m_i$ has a positive tilt, then the activity written out along $\vm$ is
read back in by $\vn$, creating positive recurrent feedback on $\kappa$.

\subsection{Why covariances become an effective circuit}

For rank one with one input,
\[
  \tau \dot{\vx}
  =
  -\vx + \vm\widehat{\kappa} + \vI u(t),
  \qquad
  \widehat{\kappa} = \frac{1}{N}\vn^\top\phi(\vx).
\]
Because $\vx$ is driven only along $\vm$ and $\vI$, the activity can be described
by low-dimensional coordinates. To derive their dynamics carefully, distinguish
the rate projection $\widehat{\kappa}(t)$ from the coefficient $\kappa(t)$ of
the state along $\vm$. Also let
$v(t)$ be the filtered input, $\tau\dot v=-v+u$. Then a state in the
low-dimensional subspace has the form
\begin{equation}
  x_i(t) = m_i\kappa(t) + I_i v(t).
  \label{eq:rank_one_state_coordinates}
\end{equation}
This form is exact when the initial condition lies in the span of $\vm$ and
$\vI$; components outside that span receive no recurrent or external drive and
decay through the leak.

Differentiate this expression and substitute it into the full neural equation:
\[
  m_i\tau\dot\kappa + I_i\tau\dot v
  =
  -m_i\kappa-I_i v+m_i\widehat{\kappa}+I_i u.
\]
Using $\tau\dot v=-v+u$ and matching the coefficient of $m_i$ gives
$\tau\dot\kappa=-\kappa+\widehat{\kappa}$. Inserting the rate projection then
closes the dynamics:
\begin{equation}
  \tau \dot{\kappa}
  =
  -\kappa
  +
  \frac{1}{N}\sum_i n_i\,
  \phi\!\left(m_i\kappa + I_i v(t)\right).
  \label{eq:rank_one_mean_field_sum}
\end{equation}
Thus the term $-\kappa$ is inherited from the single-neuron leak, while the
summation is the recurrent rate pattern read out by $\vn$. The state coordinate
$\kappa$ and the rate projection $\widehat{\kappa}$ are equal at a fixed point,
but need not be equal during a transient. They are often both denoted by
$\kappa$ when that distinction is not important. Below, we also return to the
common shorthand of writing $u$ for the filtered input coordinate $v$; for a
constant or slowly varying input, $v$ simply follows $u$.

Mean-field theory is the large-population step that turns this empirical average
over a particular set of neurons into an average over a statistical population.
If the loading vectors $\mathbf{a}_i$ are independent samples from
$p(\mathbf{a})$, then the law of large numbers gives
\[
  \frac{1}{N}\sum_i f(\mathbf{a}_i)
  \longrightarrow
  \int f(\mathbf{a})p(\mathbf{a})\,d\mathbf{a}
  =
  \mathbb{E}_{p}[f(\mathbf{a})]
\]
as $N$ becomes large. Here
$f(\mathbf{a})=n\phi(m\kappa+Iu)$, so the finite-network equation becomes
\begin{equation}
  \tau \dot{\kappa}
  =
  -\kappa
  +
  \mathbb{E}_{(I,n,m,w)\sim p(\mathbf{a})}
  \left[
    n\,\phi(m\kappa + Iu)
  \right].
  \label{eq:rank_one_mean_field_expectation}
\end{equation}
This replacement does not assume that all neurons have the mean loading or the
mean activity. It keeps their heterogeneity through the joint distribution of
$I,n,m,$ and $w$; it only removes the dependence on the identity of each finite
sample. The approximation becomes self-averaging: two sufficiently large
networks drawn from the same $p(\mathbf{a})$ have nearly the same latent
dynamics.

For a zero-mean Gaussian loading distribution, $p(\mathbf{a})$ is completely
specified by its covariance matrix. To see how its entries enter, set
$h=m\kappa+Iu$. Gaussian integration by parts gives
\begin{equation}
  \mathbb{E}\!\left[n\phi(h)\right]
  =
  \left(\sigma_{nm}\kappa+\sigma_{nI}u\right)
  \underbrace{\mathbb{E}\!\left[\phi'(h)\right]}_{g(\kappa,u)},
  \label{eq:rank_one_gaussian_mean_field}
\end{equation}
where $g(\kappa,u)$ is the average neural gain. Thus the covariances determine
the available input and feedback pathways, while the nonlinearity changes their
instantaneous strength through $g$. For $\tanh$, this gain decreases as more
neurons saturate. If the loading distribution is not Gaussian, higher-order
features of $p(\mathbf{a})$ can matter as well, so covariances alone need not
determine the dynamics.

If activity is close to the linear regime of $\tanh$, then
$g(\kappa,u)\approx 1$ (equivalently,
$\phi(m\kappa + Iu) \approx m\kappa + Iu$), and
\begin{equation}
  \tau \dot{\kappa}
  \approx
  -\kappa
  +
  \sigma_{nm}\kappa
  +
  \sigma_{nI}u.
  \label{eq:rank_one_linear_covariance}
\end{equation}
The readout has the analogous approximation
\begin{equation}
  z(t)
  =
  \frac{1}{N}\sum_i w_i\phi(x_i)
  \approx
  \sigma_{wm}\kappa + \sigma_{wI}u.
  \label{eq:rank_one_readout_covariance}
\end{equation}

So, in the simplest rank-one case:
\begin{itemize}
  \item $\sigma_{nI}$ controls how strongly the input enters the latent variable;
  \item $\sigma_{nm}$ controls recurrent feedback and therefore the integration
  timescale;
  \item $\sigma_{wm}$ controls how strongly the latent variable is visible in
  the output.
\end{itemize}

For rank $R$, the same idea becomes a small recurrent circuit with variables
$\kappa_1,\ldots,\kappa_R$:
\begin{equation}
  \tau \dot{\kappa}_r
  =
  -\kappa_r
  +
  \mathbb{E}
  \left[
    n^{(r)}
    \phi\!\left(
      \sum_{q=1}^{R}m^{(q)}\kappa_q
      +
      \sum_s I^{(s)}u_s
    \right)
  \right].
  \label{eq:rank_R_mean_field_expectation}
\end{equation}
In the linear regime, the effective coupling from $\kappa_q$ to $\kappa_r$ is
set by $\sigma_{n^{(r)}m^{(q)}}$, and the drive from input $u_s$ into
$\kappa_r$ is set by $\sigma_{n^{(r)}I^{(s)}}$. This is why the paper draws the
reduced system as an effective circuit: each collective variable is like a unit,
and the covariances in connectivity space become the couplings between those
units.

\subsection{Mean-field theory and the equivalent-circuit task}

The previous subsection gives the compact mean-field equation. This subsection
unpacks what that approximation does and how to use it for the assignment. For
clarity, we keep the filtered input coordinate $v$ explicit rather than replacing
it by $u$.

\paragraph{Step 1: start from the finite trained network.}
For a particular set of trained loading vectors, the rank-one latent dynamics are
\begin{equation}
  \tau\dot\kappa
  =
  -\kappa
  +
  \frac{1}{N}\sum_{i=1}^{N}
  n_i\phi(h_i),
  \qquad
  h_i=m_i\kappa+I_i v,
  \label{eq:mf_task_finite}
\end{equation}
coupled to $\tau\dot v=-v+u$. The quantity $h_i$ is the total low-dimensional
input current to neuron $i$. Neurons differ because their coordinates $m_i$ and
$I_i$ differ, even though all of them share the same macroscopic variables
$\kappa$ and $v$.

Mean-field theory does \emph{not} replace every neuron by an average neuron. It
replaces the average of many heterogeneous neurons by an expectation over the
distribution from which their loadings are drawn:
\[
  \frac{1}{N}\sum_i n_i\phi(h_i)
  \longrightarrow
  \mathbb{E}\!\left[n\phi(h)\right].
\]
The individual variation remains inside this expectation. What disappears is
the dependence on the identity of a particular finite sample of neurons.

\paragraph{Step 2: find the distribution of neural inputs.}
Assume the loading coordinates $(m,n,I,w)$ are jointly zero-mean Gaussian. For
fixed $\kappa$ and $v$,
\[
  h=m\kappa+Iv
\]
is then Gaussian as well. Its variance is
\begin{equation}
  \Delta^2(\kappa,v)
  =
  \sigma_m^2\kappa^2
  +
  \sigma_I^2v^2
  +
  2\sigma_{mI}\kappa v.
  \label{eq:mf_task_delta_general}
\end{equation}
Here $\sigma_m^2=\mathbb{E}[m^2]$, $\sigma_I^2=\mathbb{E}[I^2]$, and
$\sigma_{mI}=\mathbb{E}[mI]$. If $\vm$ and $\vI$ are orthogonal in the
large-population sense, then $\sigma_{mI}=0$ and
\begin{equation}
  \Delta
  =
  \sqrt{\sigma_m^2\kappa^2+\sigma_I^2v^2}.
  \label{eq:mf_task_delta_orthogonal}
\end{equation}
Thus $h$ can be represented as $h=\Delta z$ with
$z\sim\mathcal{N}(0,1)$. Intuitively, $\Delta$ measures how widely the neurons
are spread across the nonlinear activation function at the current state.

\paragraph{Step 3: average the neuronal gain.}
The local slope $\phi'(h)$ measures how responsive a neuron is to a small change
in its input. Its population average is
\begin{equation}
  g(\Delta)
  =
  \left\langle\phi'\right\rangle(\Delta)
  =
  \frac{1}{\sqrt{2\pi}}
  \int_{-\infty}^{\infty}
  \phi'(\Delta z)e^{-z^2/2}\,dz.
  \label{eq:mf_task_gain}
\end{equation}
For $\phi=\tanh$, $\phi'(h)=\operatorname{sech}^2(h)$. When $\Delta$ is small,
most neurons are near the high-gain center of $\tanh$ and $g(\Delta)\approx1$.
When $\Delta$ is large, more neurons are saturated and $g(\Delta)$ decreases.
This single scalar is how the mean-field circuit retains the effect of the
nonlinearity.

\paragraph{Step 4: turn loading covariances into effective couplings.}
Because $n$ and $h$ are jointly Gaussian, Gaussian integration by parts gives
\begin{align}
  \mathbb{E}\!\left[n\phi(h)\right]
  &=
  \operatorname{Cov}(n,h)\,
  \mathbb{E}\!\left[\phi'(h)\right]
  \notag\\
  &=
  \left(\sigma_{nm}\kappa+\sigma_{nI}v\right)g(\Delta).
  \label{eq:mf_task_stein}
\end{align}
The two terms have a direct circuit interpretation. The input is written along
$\vI$ and read by $\vn$, so $\sigma_{nI}$ sets the input-to-latent pathway.
The latent state is written along $\vm$ and read back by $\vn$, so
$\sigma_{nm}$ sets the recurrent feedback loop. The nonlinearity multiplies
both pathways by the current population gain.

Define the state-dependent effective couplings
\begin{equation}
  \widetilde{\sigma}_{ab}(\kappa,v)
  =
  \sigma_{ab}g\!\left(\Delta(\kappa,v)\right).
  \label{eq:mf_task_effective_covariance}
\end{equation}
The equivalent circuit is then
\begin{equation}
  \boxed{
  \begin{aligned}
    \tau\dot v
    &= -v+u,\\
    \tau\dot\kappa
    &= -\kappa
       +g(\Delta)\left(\sigma_{nm}\kappa+\sigma_{nI}v\right).
  \end{aligned}}
  \label{eq:mf_task_system}
\end{equation}
It is called one-dimensional because there is one \emph{recurrent} internal
variable, $\kappa$. Formally, the augmented system also contains $v$, but $v$ is
only an input filter: it is determined by $u$ and receives no feedback from
$\kappa$.

The readout follows from the same calculation:
\begin{equation}
  z_{\mathrm{MF}}
  =
  \mathbb{E}\!\left[w\phi(h)\right]
  =
  g(\Delta)\left(\sigma_{wm}\kappa+\sigma_{wI}v\right).
  \label{eq:mf_task_output}
\end{equation}
Thus $\sigma_{wm}$ makes the latent decision variable visible to the output,
while $\sigma_{wI}$ describes any direct input-to-output pathway.

\paragraph{What the assignment is asking you to test.}
The goal is not merely to integrate another differential equation. It is to test
whether a handful of loading-space statistics preserve the computation learned
by the full network. A useful sequence is:
\begin{enumerate}
  \item \textbf{Extract the trained statistics.} Inspect the empirical loading
  means and compute $\sigma_{nm}$, $\sigma_{nI}$, $\sigma_{wm}$,
  $\sigma_{wI}$, $\sigma_m^2$, $\sigma_I^2$, and $\sigma_{mI}$. The formulas
  above assume zero means. Centering is appropriate when testing that model; if
  the trained means are appreciable, record them because a mean-field model that
  discards them is testing a different loading distribution.

  \item \textbf{Check the finite-sum reduction first.} Simulate
  Eq.~\eqref{eq:mf_task_finite} with the actual trained loadings. If this does
  not track the full RNN, first check the coordinate normalization, initial
  condition, integration step, and the assumption that activity is confined to
  the span of $\vm$ and $\vI$.

  \item \textbf{Simulate the Gaussian mean-field circuit.} For the same input
  $u(t)$ and time step as the full RNN, update $v$ and $\kappa$ using
  Eq.~\eqref{eq:mf_task_system}. At every step, recompute $\Delta$ and evaluate
  $g(\Delta)$ by numerical quadrature, a precomputed lookup table, or Gaussian
  samples.

  \item \textbf{Reconstruct behavior.} Use Eq.~\eqref{eq:mf_task_output} to
  obtain the mean-field output. Apply the same decision rule used for the full
  network, such as the sign of the final output, and compare accuracy,
  psychometric curves, latent trajectories, and output trajectories.

  \item \textbf{Diagnose any mismatch.} If the finite-sum model succeeds but
  the Gaussian mean-field model fails, the one-Gaussian loading description is
  probably missing structure, or finite-size effects are important. If both
  reduced models fail, the issue is more likely the coordinate reduction or its
  normalization. The paper's supplied covariance values are a useful reference
  circuit, but reproducing them is not a substitute for diagnosing the trained
  network. Before treating supplied numbers as entries of a Gaussian covariance
  matrix, match the paper's scaling convention and verify that the matrix is
  positive semidefinite; in particular,
  $|\sigma_{ab}|\leq\sigma_a\sigma_b$ must hold.
\end{enumerate}

For intuition, the full network and the mean-field circuit sit at three levels:
\[
  \begin{array}{c}
  \text{trained neurons}\;(I_i,n_i,m_i,w_i)
  \\[0.5em]
  \Downarrow\;\text{average over the loading cloud}
  \\[0.5em]
  \text{covariances}\;\sigma_{nI},\sigma_{nm},\sigma_{wm},\ldots
  \\[0.5em]
  \Downarrow\;\text{multiply by the current gain }g(\Delta)
  \\[0.5em]
  \text{effective input, feedback, and readout couplings.}
  \end{array}
\]
Low rank says that only one recurrent coordinate must be followed. The Gaussian
mean-field assumption says that the cloud of individual neurons can be replaced
by its covariance geometry. The gain $g(\Delta)$ then tells us how much of that
geometric coupling is currently usable rather than lost to saturation.

\paragraph{Normalization convention.}
Throughout this note, $\kappa$ is the coefficient in
$\vx=\vm\kappa+\vI v$. If $\vm\perp\vI$, this coefficient is
\begin{equation}
  \kappa
  =
  \frac{\vm^\top\vx}{\lVert\vm\rVert^2}.
  \label{eq:mf_task_kappa_coefficient}
\end{equation}
Some presentations instead use
$\vm^\top\vx/\lVert\vm\rVert$, the projection length along the unit vector
$\vm/\lVert\vm\rVert$. Both conventions are valid, but their numerical
$\kappa$ values differ by a factor of $\lVert\vm\rVert$, so the state
decomposition and covariance factors must be rescaled consistently. Likewise,
Eq.~\eqref{eq:mf_task_delta_orthogonal} contains $v$, not the raw input $u$,
unless one explicitly makes the slow-input approximation $v\approx u$.

\subsection{Single population versus multiple populations}

A single Gaussian cloud means all neurons are samples from one statistical
population:
\[
  p(\mathbf{a}) = \mathcal{N}(0,\Sigma).
\]
This can already implement many computations. Increasing the rank $R$ increases
the number of internal variables $\kappa_r$, so the network has more internal
degrees of freedom.

The paper then asks a separate question: when is one cloud not enough? To answer
this, it allows a mixture of $P$ Gaussian populations:
\begin{equation}
  p(\mathbf{a})
  =
  \sum_{p=1}^{P}
  \alpha_p \mathcal{N}(0,\Sigma_p).
  \label{eq:mixture_loading_gaussian}
\end{equation}
Here $\alpha_p$ is the fraction of neurons in population $p$, and $\Sigma_p$ is
that population's covariance matrix. The clusters are centered at the origin in
the paper's model, so what distinguishes populations is not their mean activity
or mean loading. What distinguishes them is their covariance structure: different
subpopulations can have different relationships between input, recurrent, and
readout patterns.

With multiple populations, the mean-field equation becomes
\begin{equation}
  \tau \dot{\kappa}_r
  =
  -\kappa_r
  +
  \sum_{p=1}^{P}\alpha_p
  \mathbb{E}_{\mathbf{a}\sim\mathcal{N}(0,\Sigma_p)}
  \left[
    n^{(r)}
    \phi\!\left(
      \sum_q m^{(q)}\kappa_q
      +
      \sum_s I^{(s)}u_s
    \right)
  \right].
  \label{eq:population_mean_field}
\end{equation}
Nonlinearity makes this more powerful than just averaging covariance matrices.
The gain $\phi'(x_i)$ can be different in different subpopulations, because an
input can push one subpopulation into a high-gain regime and another into a
low-gain or saturated regime. In a local linearization, the effective covariance
has the form
\begin{equation}
  \widetilde{\sigma}_{ab}
  =
  \sum_{p=1}^{P}
  \alpha_p
  \sigma_{ab}^{(p)}
  \langle \phi' \rangle_p.
  \label{eq:gain_weighted_covariance}
\end{equation}
The same anatomical connectivity can therefore have different effective
low-dimensional couplings depending on which subpopulations are active and what
their gains are.

This is the paper's distinction between rank and population structure:
\begin{itemize}
  \item $R$ controls how many internal collective variables are available;
  \item $P$ controls how many statistically distinct neuron groups shape the
  dynamics of those variables.
\end{itemize}

\subsection{The paper's analysis pipeline}

The paper analyzes trained networks with the following logic.

\begin{enumerate}
  \item \textbf{Train low-rank RNNs on a task.} For each behavioral task, the
  authors search for a minimal recurrent rank $R$ that can solve it.

  \item \textbf{Build the loading matrix.} Each neuron becomes one row, with
  columns given by its input, recurrent, and readout loadings. For example, with
  one input, one readout, and two recurrent modes, the loading space has six
  coordinates:
  \[
    (I_i,n_i^{(1)},m_i^{(1)},n_i^{(2)},m_i^{(2)},w_i).
  \]

  \item \textbf{Fit clusters in loading space.} The authors fit Gaussian
  clusters to the cloud of neuron loadings. They progressively increase the
  number of clusters $P$.

  \item \textbf{Estimate each cluster's covariance structure.} For every fitted
  population, they compute the covariance matrix between patterns. This matrix
  is the compact summary of that population's connectivity geometry.

  \item \textbf{Resample networks from the fitted distribution.} They generate
  new networks by sampling neurons from the fitted Gaussian population or mixture
  of populations. If the resampled networks solve the task as well as the
  original trained networks, then the fitted connectivity-space statistics have
  captured the essential computational structure.

  \item \textbf{Find the minimal number of populations.} The minimal $P$ is the
  smallest number of clusters whose resampled networks still perform the task.

  \item \textbf{Use mean-field theory to identify key parameters.} Once the
  relevant covariances are known, the paper builds reduced low-dimensional
  models that keep only the important covariance entries. This reveals the
  mechanism in terms of input drive, recurrent feedback, coupling between
  latent variables, and readout.
\end{enumerate}

The important methodological point is that clustering is not used merely for
visualization. It is tested causally by resampling: if a simplified
connectivity-space distribution can regenerate networks with the same behavior,
then that distribution is a valid reduced description of the trained network.

\subsection{How the task examples fit the framework}

The screenshots summarize the paper's minimal rank and minimal population
counts:
\begin{center}
\begin{tabular}{@{}lll@{}}
\toprule
Task & Minimal rank & Minimal populations \\
\midrule
Perceptual decision making & $R=1$ & $P=1$ \\
Multi-sensory decision making & $R=1$ & $P=1$ \\
Parametric working memory & $R=2$ & $P=1$ \\
Context-dependent decision making & $R=1$ & $P=2$ \\
Delay-match-to-sample with two items & $R=2$ & $P=2$ \\
\bottomrule
\end{tabular}
\end{center}

For perceptual decision making, the network has one input, one readout, and one
recurrent mode, so the loading space is four-dimensional: $(I,n,m,w)$. A single
Gaussian population is enough. The key covariances have direct interpretations:
\begin{itemize}
  \item $I$-$n$ covariance determines how stimulus input drives $\kappa$;
  \item $n$-$m$ covariance determines positive feedback and integration;
  \item $m$-$w$ covariance determines how $\kappa$ drives the readout.
\end{itemize}
This is the cleanest example of the connectivity-space idea: a four-dimensional
point cloud, summarized by a few covariances, becomes a one-dimensional
integrator.

For parametric working memory, the network needs $R=2$. The loading space has
six dimensions: one input, one readout, and two pairs of recurrent patterns. The
paper finds that one population is still enough, but the covariance structure now
creates two different internal variables. One mode has strong positive feedback,
so it can maintain the first stimulus through a delay. The other mode is more
transient and represents stimulus information without the same persistent
feedback. The readout combines the two output directions to compute a difference
between the two stimulus values.

For context-dependent decision making, increasing rank alone is not the key
move. A rank-one network can solve the task, but it needs two populations. The
reason is that context-dependent computations require the same inputs and latent
variable to be routed differently depending on context. Distinct subpopulations
allow context inputs to modulate gains and effective covariances differently in
different groups of neurons. This changes the effective circuit without needing
many more recurrent dimensions.

For delay-match-to-sample with two items, the paper reports that both extra
rank and extra population structure are needed: $R=2$ and $P=2$. In this kind of
task, the network needs multiple internal variables and population-specific
organization to compare items flexibly.

\subsection{How to analyze connectivity space in your rank-one model}

After training the assignment model, the direct analogue of the paper's analysis
is to form the $N \times 4$ loading matrix
\[
  A =
  \left[
  \begin{array}{cccc}
  I_1 & n_1 & m_1 & w_1\\
  I_2 & n_2 & m_2 & w_2\\
  \vdots & \vdots & \vdots & \vdots\\
  I_N & n_N & m_N & w_N
  \end{array}
  \right].
\]
Then inspect the covariance matrix
\[
  \Sigma = \frac{1}{N}A^\top A
\]
after centering columns if their empirical means are not close to zero. The
entries to look at first are:
\begin{itemize}
  \item $\Sigma_{I,n}$: input-to-latent drive;
  \item $\Sigma_{n,m}$: recurrent feedback on the latent variable;
  \item $\Sigma_{m,w}$: latent-to-output readout alignment;
  \item $\Sigma_{I,w}$: direct input visibility in the readout, if present.
\end{itemize}

A minimal PyTorch diagnostic is:
\begin{lstlisting}[style=python]
with torch.no_grad():
    A = torch.stack([model.I, model.n, model.m, model.w], dim=1)
    A = A - A.mean(dim=0, keepdim=True)
    Sigma = A.T @ A / A.shape[0]

print(Sigma)
\end{lstlisting}

The scatterplots that correspond to the paper's loading-space projections are
just pairwise plots of the columns of $A$: $I$ versus $n$, $n$ versus $m$, $m$
versus $w$, and so on. These plots are not only descriptive. They tell you which
statistical relationships training created. If the trained network integrates
evidence, you should expect the learned $\vn$ and $\vm$ to create recurrent
feedback, and the learned $\vn$ to align with the fixed input direction enough
for stimulus information to enter $\kappa$.

\subsection{The main takeaway}

Connectivity space is the paper's way of turning a large trained network into a
small statistical object. Low rank gives the network a small number of latent
variables. The loading-space distribution tells us how the neurons arrange
input, recurrent, and readout weights so those latent variables perform a task.
The covariance matrix of the loading cloud then becomes the parameter matrix of
an effective low-dimensional circuit.
