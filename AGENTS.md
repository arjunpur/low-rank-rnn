# Agent Instructions

## Coding Guidelines

1. Write simple, easy-to-read code.
   Prefer clear control flow, straightforward data structures, and descriptive names.

2. Prefer simplifying or deleting code over adding more.
   Remove unnecessary logic and reduce complexity whenever possible.

3. Refactor proactively for clarity.
   Split code into focused, well-named modules and functions when doing so makes the code easier to understand and maintain.

4. Do not add anything that is not needed for the current task.
   Avoid speculative features, premature abstractions, and unnecessary defensive handling.

5. Make incremental changes.
   Keep each change small, focused, and easy to review. Extend the implementation only as requirements become clear.
